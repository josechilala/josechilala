### 🛒 [WebApp Compras — Compra Assistida](https://github.com/josechilala/WebApp_Compras)

Plataforma de **compra assistida para mercados locais**, conectando clientes, mercados parceiros e compradores-entregadores.

O cliente cria sua lista de compras e acompanha o pedido, enquanto o comprador realiza a separação dos produtos, informa indisponibilidades ou substituições e executa o fluxo de entrega.

O projeto trabalha com regras de negócio, controle de concorrência, auditoria, autorização e separação entre API, serviços, repositórios e persistência.

**Conceitos:** ASP.NET Core • APIs REST • Entity Framework Core • Clean Code • SOLID • Repository Pattern • Autenticação e Autorização

---

### 💳 [ActDigital.Account.Api — API de Movimentações de Conta](https://github.com/josechilala/ActDigital.Account.Api)
API para gerenciamento de **movimentações financeiras de conta**, permitindo registrar créditos e débitos, consultar saldo e acessar o histórico de movimentações.

A regra de negócio é encapsulada no domínio, impedindo operações de débito que resultem em saldo negativo. A solução utiliza persistência em memória thread-safe e mantém separação entre domínio, serviços e infraestrutura.

Principais recursos:

- Consulta de saldo
- Registro de créditos e débitos
- Histórico de movimentações
- Consulta de movimentação por identificador
- Validação da regra de saldo não negativo
- Testes automatizados
- Documentação OpenAPI/Swagger

**Tecnologias:** C# • .NET 10 • Minimal API • OpenAPI • Clean Architecture • SOLID • Clean Code • Testes
